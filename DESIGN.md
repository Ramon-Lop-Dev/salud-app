# Design System

This design system defines a high‑contrast, large‑type, mobile‑first UI for the Salud App.

- Primary color: #2563eb (blue)
- Background color: #f8fafc (light gray)
- Text color: #0f172a (dark gray)
- Font family: PLUS_JAKARTA_SANS
- Body font size: 18px (minimum)
- Button minimum height: 48px
- Use ample spacing and clear focus outlines.
